# Figures

The five PNGs in `figures/` are original diagrams prepared for the accompanying paper.

1. `fig1_audit_pipeline.png` — artifact-first audit workflow.
2. `fig2_repeat_variation.png` — score variation across repeated baseline payload observations and one-run follow-up trials.
3. `fig3_regime_comparison.png` — descriptive comparison of core and non-core execution envelopes; not a causal estimate.
4. `fig4_factor_intervals.png` — exploratory payload-level factor contrasts with heuristic intervals.
5. `fig5_lora_null_update.png` — why a zero LoRA-B matrix produces a zero standard LoRA update.
